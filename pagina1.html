Introdução aos MVC

O padrão MVC (Model-View-Controller) é uma arquitetura de software utilizada no desenvolvimento de aplicações para separar a lógica de negócios, a interface do usuário e o controle dos dados.


Componentes do MVC

    • Model(Modelo) Representa os dados e a lógica de negócios da aplicação.
    • View(Visão) Responsável pela interface com o ususário e exibição dos dados.
    • Controller: Intermedia a comunicação entre o Model e a View.
